# Alcaline – Software Agency Landing Page

A modern and responsive software agency landing page built with **React.js** and **Tailwind CSS**. This project is a Figma-to-React conversion focused on creating a clean user interface, responsive layouts, and smooth user interactions.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices.
- Modern and clean UI.
- Smooth scrolling navigation between sections.
- Animated elements using AOS (Animate On Scroll).
- Services and development approach sections.
- Case studies showcase.
- Client testimonials section.
- Embedded YouTube video.
- Contact and Hire Us sections.

## 🛠️ Tech Stack

- **React.js** – Frontend library
- **Tailwind CSS** – Styling and responsive layouts
- **JavaScript** – Application functionality
- **React Scroll** – Smooth scrolling navigation
- **AOS** – Scroll animations
